# assets

## hero.jpg — 서막 실사 사진

`assets/hero.jpg` 가 있으면 첫 화면이 **해당 부동산 실사 사진**으로 시작한다.
스크롤을 내리면 형광 보라 밴드가 아래에서 위로 훑고 지나가며 사진이 벗겨지고,
그 자리에 같은 건물의 레고 버전이 드러난다. 파일이 없으면 이 단계를 건너뛰고
레고 건물에 보라 스윕만 지나간 뒤 곧바로 다음 챕터로 이어진다 (오류 없음).

현재 파일: 1206×1812 세로 사진, 밤 정면 컷.

### 위치는 CSS 로 맞추지 않는다

사진은 화면에 고정돼 있지 않다. `js/v2/main2.js` 의 `fitHeroPhoto()` 가 **매 프레임**
3D 건물의 정면 실루엣(`building.mass`)을 화면에 투영하고, 사진 속 건물 사각형을 그 위에 맞춰 앉힌다.
그래서 카메라·화면비가 바뀌어도 사진과 레고가 같은 자리, 같은 크기로 선다.
`css/style.css` 에서 `background-position`/`background-size` 를 건드리면 매 프레임 덮어써지거나 정합이 깨진다.

### 사진을 바꿀 때

1. 파일을 교체한다(이름을 바꾸려면 `main2.js` 의 `PHOTO_SRC`).
2. `main2.js` 의 `PHOTO_MASS` 를 새 사진에 맞게 다시 잰다 — 원본 픽셀 기준으로
   좌: 본체 좌측 끝(캔틸레버 슬래브) / 우: 우측 끝 / 상: 지붕 앞날 / 하: 건물이 땅에 닿는 선.
   좌측 별동·주차장은 뺀다(3D 매싱의 실루엣과 같은 범위여야 한다).
   현재 값은 `{ x0: 186, y0: 551, x1: 1037, y1: 1146 }`.
3. 레고 매싱 폭은 이 사진에 맞춰 놓았다. 새 사진의 건물 비율이 다르면
   `js/v2/building3.js` 의 슬래브·지붕 좌우 끝도 다시 맞춘다 — 측정 방법은 루트 README 의 '검수' 참고.

권장 사양
- 3D 서막 카메라와 같은 **정면·눈높이** 앵글일수록 치환이 자연스럽다
- 배경이 어두운 밤/블루아워 사진이면 씬과 가장 잘 붙는다 (사진 여백은 검정으로 이어 붙는다)
- 1~2MB 이하로 압축 — 단일 HTML 번들에 base64 로 그대로 들어간다
